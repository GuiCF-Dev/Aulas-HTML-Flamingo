# Aulas-HTML-Flamingo
Repositório contendo atividades realizadas na Faculdade Flamingo, focadas no aprendizado e aplicação dos fundamentos de HTML e CSS, incluindo a construção de páginas web, estilização de interfaces e boas práticas de desenvolvimento front-end.

# 🎓 Atividades de HTML e CSS - Faculdade Flamingo

## 📖 Sobre o Repositório

Este repositório reúne uma coleção de atividades e projetos desenvolvidos durante a graduação na **Faculdade Flamingo**.

Os exercícios têm como objetivo ensinar e consolidar conceitos essenciais de **HTML** e **CSS**, promovendo a criação de interfaces web, estilização de páginas e a compreensão das boas práticas de desenvolvimento Front-End.

A metodologia utilizada segue o conceito de **Baby Steps (Pequenos Passos)**, onde cada atividade é construída para reforçar um conjunto específico de habilidades, permitindo uma evolução gradual e consistente no aprendizado.

---

## 🎯 Objetivos

* Aprender os fundamentos do HTML.
* Compreender a estrutura de páginas web.
* Aplicar estilização utilizando CSS.
* Desenvolver interfaces responsivas.
* Praticar organização e manutenção de código.
* Evoluir gradualmente através de exercícios práticos.
